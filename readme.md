# 🤖 AutoML Dashboard Pro

## 🚀 Overview
Complete Automated Machine Learning Dashboard with **35+ models** including:
- Traditional Models (Linear, Ridge, Lasso, etc.)
- Ensemble Models (Random Forest, Gradient Boosting, etc.)
- Advanced Models (XGBoost, LightGBM, CatBoost)
- Deep Learning (ANN, CNN, RNN, LSTM)

## ✨ Features
- 📁 Data Upload (CSV, Excel)
- ⚙️ Auto Configuration
- 🤖 35+ ML Models
- 🧠 Deep Learning
- 📊 Interactive Visualizations
- 🔧 Hyperparameter Tuning
- 📈 Model Comparison
- 📄 Report Generation
